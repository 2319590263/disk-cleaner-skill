# Disk Cleaner Skill

## 描述
一个全面的电脑磁盘清理和优化工具，用于检查、分析和清理Windows系统中的垃圾文件、重复文件、临时文件等，释放磁盘空间并优化系统性能。

## 适用场景
- 电脑运行缓慢，需要清理垃圾文件
- 磁盘空间不足，需要释放空间
- 定期系统维护和优化
- 检查磁盘健康状态
- 清理重复文件和应用缓存

## 功能特性

### 1. 磁盘状态分析
- 检查C盘和D盘使用情况
- 分析主要目录占用空间
- 识别大文件和重复文件

### 2. 垃圾文件清理
- 临时文件清理（.tmp, .log, .bak等）
- 浏览器缓存清理
- Windows更新缓存清理
- 回收站清空
- 安装包清理

### 3. 应用优化
- node_modules目录优化
- 应用程序缓存清理
- 重复文件检测和清理
- 虚拟硬盘文件管理

### 4. 系统健康检查
- 磁盘错误检查建议
- 碎片整理建议
- 空间使用健康度评估

## 使用方法

### 基本命令
```bash
# 运行完整清理流程
openclaw agent --skill disk-cleaner --message "清理电脑垃圾文件"

# 只检查不清理
openclaw agent --skill disk-cleaner --message "检查磁盘状态"

# 清理特定项目
openclaw agent --skill disk-cleaner --message "清理临时文件"
```

### 交互模式
Skill支持交互式操作，会：
1. 先列出可清理项目
2. 请求用户确认
3. 执行清理并报告结果
4. 提供后续建议

## 安全特性
- ✅ 危险操作前请求确认
- ✅ 重要文件自动保留
- ✅ 支持撤销操作（回收站）
- ✅ 详细的清理报告
- ✅ 备份重要数据建议

## 文件结构
```
disk-cleaner/
├── SKILL.md              # 技能说明文档
├── scripts/              # 清理脚本
│   ├── analyze.ps1      # 磁盘分析脚本
│   ├── cleaner.ps1      # 清理执行脚本
│   └── utils.ps1        # 工具函数
├── references/          # 参考文档

│   └── safety.md       # 安全操作指南

```

## 配置选项
可在`config.json`中配置：
- 排除目录列表
- 最大文件保留天数
- 安全清理阈值
- 自动备份设置

## 依赖
- Windows PowerShell 5.1+
- 管理员权限（部分功能）
- 足够的磁盘空间进行临时操作

## 注意事项
1. 部分操作需要管理员权限
2. 清理前建议备份重要数据
3. 系统文件不会被删除
4. 用户文档和设置会被保留
